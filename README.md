# Teste Técnico

Repositório contendo os projetos do teste técnico:

1. **`calculo-comissao-vendas`**: Leitura de vendas via JSON e cálculo de comissões por vendedor.
2. **`estoque-vendas`**: Gestão e controle de estoque de vendas.
3. **`juros-multa-vencimento`**: Cálculo de juros e multas para títulos/faturas vencidas.
